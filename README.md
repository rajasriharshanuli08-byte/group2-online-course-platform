# Group 2: Online Course Platform (SkillSphere)

A complete, responsive online learning platform with course categories, course cards, instructor profiles, student reviews, and interactive enrollment workflows.

## Assignment Overview
- **Category:** Group 2 — Project 1 (Online Course Website)
- **Objective:** Create an online learning webpage with course categories, course cards, instructor profiles, course information, student reviews, and enrollment options.
- **Tech Stack:** HTML5, CSS3 (CSS Grid, Flexbox, Custom Shadows), Vanilla JavaScript, FontAwesome Icons, Google Fonts.

## Features
1. **Top Announcement Banner:** Highlights promotional discounts and flash coupon codes.
2. **Search & Navigation:** Real-time course search filter and mobile responsive drawer.
3. **Hero Section:** Value proposition headline, search input, verified student ratings, social proof avatars, and floating credential metrics.
4. **Course Categories:** 6 key tracks (Web Dev, AI & Machine Learning, Data Science, UI/UX Design, Cloud & DevOps, Cybersecurity) with category badges and course counts.
5. **Featured Course Cards:** Course thumbnails with bestseller badges, difficulty levels, star ratings, instructor metadata, total hours, lesson counts, verified tags, and pricing.
6. **Instructor Profiles:** Industry mentor cards highlighting credentials, former companies (Meta, AWS, etc.), student reach, and ratings.
7. **Student Reviews & Testimonials:** Real student quotes, career transformation stories, and verification stamps.
8. **Enrollment Modal Dialog:** Interactive popup allowing users to enter details, choose self-paced vs. mentorship tracks, and complete enrollment.
